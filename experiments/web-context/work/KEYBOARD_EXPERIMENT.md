主屏打开短信草稿并调出键盘。每阶段电脑回车后有 5 秒准备，随后在手机连续打字；出现异常按 Ctrl+C。按阶段记录：A 创建副屏并打开设置；B 点击搜索框、持续输入约 10 秒；C 副屏一次返回；D 关闭副屏。仅在电脑副屏确实显示设置首页、顶部搜索框可见时输入 `yes`，否则停止。坐标 (540,410) 来自这台 HONOR Magic3 的 1080×2400/420 实测设置页，不是通用定位器。

同时记录主屏焦点、IME 所属显示、键盘显示状态和用户观察。任何异常/未看清/采样缺失都不会报通过。需分别记录“是否进入副屏输入界面”和“副屏软键盘是否显示”；进入输入界面但没有副屏软键盘，不等于文字输入可用或不可用。结果在本实验目录 `outputs/keyboard-input-*`，只保存副屏 PNG；不保存主屏文字，不上传。

回到基线：先关闭实验副屏；若手机主屏键盘异常，先退出草稿再进入恢复输入（不要发送）。然后运行 `python3 /Users/yishanma/Documents/Codex/wellphone-versioned/run.py baseline`。不需覆盖文件或 git reset。代码基线不等于手机状态快照，不能保证自动恢复系统运行状态。

文字输入另见 [阶段 2：固定 ASCII 探针](ASCII_EXPERIMENT.md)。两个入口独立；原 keyboard 模式仍然只请求键盘，不输入文字。
